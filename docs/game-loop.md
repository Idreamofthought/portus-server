# Game Loop

The core loop of Portus is:

**Explore -> Discover -> React -> Survive -> Save -> Continue**

## Explore

Move through the landscape and inspect terrain, resources, ruins, and signs.

## Discover

Find artifacts or fragments and unlock Codex entries.

## React

Read warnings, prepare resources, and choose an appropriate response.

## Survive

Manage the settlement through disasters, rituals, and recovery.

## Save

Record progress through the local save format and authenticated cloud save.

## Continue

Push deeper into the world while preserving what the settlement has learned.
