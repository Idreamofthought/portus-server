# Timekeeper Set

## Reckoning Bone

A water-dark bone carrying three paths of marks. It is not a command over the
past; it is permission to notice repetition.

**Effect:** Reveals the next day-night transition and unlocks *The Lore of
Time*.

## Wanderers' Dial

A bronze ring with seven movable pins. The pins never settle in the same
pattern twice.

**Effect:** Once per cycle, preview one available warning before it escalates.

## Sixtyfold Thread

A braided cord divided into sixty knots, strong enough to be shared among
many hands.

**Effect:** Once per cycle, redistribute up to 60 stored basic resources
between two stores without loss.

## Calendar of Returns

Twelve pale leaves bound around a blank center. The final page is always the
one the Keeper has not yet lived.

**Set bonus:** With all four artifacts, the first warning in each cycle grants
a short preparation window instead of applying its immediate penalty.
